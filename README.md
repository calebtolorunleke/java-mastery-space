# Java Mastery Space ☕

A hands-on, daily engineering roadmap dedicated to mastering Core Java, Object-Oriented Programming, and production-grade software development principles.

## 🎯 Purpose
As a full-stack engineer expanding my backend depth, this repository serves as a structured, code-first space to learn, build, test, and commit Java applications daily alongside my Master’s studies in Computer Science at Northeastern University.

## ⚙️ Development Environment
* **Language:** Java (JDK 21)
* **IDE:** Visual Studio Code (Java Extension Pack)
* **Build System:** Gradle / Maven
* **Version Control:** Git & GitHub

---

## 🛠️ Execution Methodology
For every core concept covered:
1. **Understand:** Deep-dive into foundational concepts and specifications.
2. **Build:** Write implementation code from scratch without relying on boilerplate generators.
3. **Test:** Validate execution logic, edge cases, and exception paths in terminal.
4. **Ship:** Commit cleanly with descriptive conventional commits and push daily.
